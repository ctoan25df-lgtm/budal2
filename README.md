# BUDAL FIELDNOTE

부달주소와 부산달리기 관련 공개 채널의 변화를 기록하고 부산·경남 생활권
정보를 함께 제공하는 독립 편집 노트입니다.

## Runtime

- Next.js 16 App Router
- React Server Components
- Native Next.js development and production builds
- OpenNext Cloudflare adapter for the hosted Worker artifact

## Commands

- `npm run dev`: start the native Next.js development server
- `npm run build`: run the native Next.js production build
- `npm run start`: serve the native Next.js production build
- `npm run worker:build`: adapt the completed Next.js build for Cloudflare
- `npm run lint`: run ESLint
- `npm test`: verify the rendered routes while the local server is running

Set `NEXT_PUBLIC_SITE_URL` when deploying to a custom domain.
